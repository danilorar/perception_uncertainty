# 理想感知与连续漏检演示 / Ideal perception versus burst loss demo

作者 / Author: Zhuo Ma · 日期 / Date: 2026-10-08

场景 1549178，原生 AEB，seed10。理想组 p=0，漏检组 Markov p=0.1、T=0.5 s、stationary。两组 dt=0.01 s、sensor=0.05 s、TTC=1.5 s、最大减速度=8.3385 m/s²、0.6 s 建立时间。批次为 `comparison_1549178_20261008T124403-779306Z`。

Scenario 1549178, native AEB, seed10. Ideal p=0; loss uses Markov p=0.1, T=0.5 s, stationary. Both use dt=0.01 s, sensor=0.05 s, TTC=1.5 s, braking=8.3385 m/s² and a 0.6 s ramp. Batch: `comparison_1549178_20261008T124403-779306Z`.

| 指标 / Metric | 理想 / Ideal | 连续漏检 / Burst loss |
|---|---:|---:|
| 首次 AEB / First AEB s | 3.280 | 3.550 |
| 触发延迟 / Trigger delay s | 0 | 0.270 |
| 碰撞 / Collision | 否 / no | 是 / yes |
| 首次接触 / First contact s | — | 4.570 |
| 接触相对速度 / Contact relative speed m/s | — | 4.108 |
| 最小真值 gap / Minimum truth gap m | 1.553 | -0.012 |
| 实际漏检率 / Realized loss | 0% | 35.87% |
| 最长检测缺失 / Longest detection loss s | 0 | 0.850 |

3.25 s 仍在连续漏检段，cone 隐藏；3.55 s 观测恢复、cone 显示，AEB 才触发。前车在漏检时仍按真实轨迹显示。cone 是感知输出可用性提示，漏检不等于硬件关闭。

At 3.25 s loss continues and the cone is hidden. At 3.55 s observations return, the cone appears and AEB triggers. The target remains visible on its true trajectory during misses. The cone signals observation availability, not hardware shutdown.

本例为说明性 seed，不代表总体风险。10% 是稳态参数，单次短场景可得 35.87% 实际缺失；同场景 T=0.5 s 的 100 seed 实验为 8/100 碰撞。首次接触截止会截断暴露和缺失段。

This is an illustrative seed rather than a population-risk estimate. The 10% setting is stationary; a short run can realize 35.87% loss. The same scene with T=0.5 s had 8/100 collisions in the 100-seed study. First-contact stopping censors exposure and bursts.

零概率等价、同 seed 复现、p=1 无目标观测、目标真值保持均通过。精选 [comparison.csv](aeb_demo_1549178_seed10_20261008/comparison.csv) 与 [manifest](aeb_demo_1549178_seed10_20261008/README.md) 可提交；本机 `results/tset_demo/` 原记录/截图不提交。

p=0 identity, same-seed reproduction, p=1 observation removal and unchanged target truth all passed. Selected comparison/manifest files are tracked; original records/snapshots under local `results/tset_demo/` are ignored.

从 acc_cpp/ 重新生成及回放 / Recreate and replay from acc_cpp/:

```bash
python3 tools/run_comparison.py --binary build/runner/acc_sim \
  --scenario ../../Data/C_original_1549178.xosc --controller aeb \
  --dropout-model markov --dropout-p 0.1 --mean-missing 0.5 --seeds 10 --validate
task_batch="$(cat results/latest.txt)"
python3 tools/replay_perception.py --run-dir "$task_batch/ideal_seed10"
python3 tools/replay_perception.py --run-dir "$task_batch/dropout_seed10"
```
