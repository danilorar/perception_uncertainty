# 输出字段

Author: Zhuo Ma

每个 AEB 运行目录包含：

- `run_config.json`：场景、AEB 开关、概率、seed、dt、阈值、减速度、输入文件 SHA256。
- `aeb_telemetry.csv`：每个仿真时刻的状态、检测、控制与碰撞。
- `run.log`：esmini 原生日志。
- `sim.dat`：esmini 回放记录。

ideal sensor 单独回放使用 `sensor_ids.csv`；纯可执行程序回放使用 `states.csv`。

| 字段 | 含义 |
| --- | --- |
| `time_s` | 仿真时间，秒 |
| `raw_detected_ids` | esmini 原始检测 ID，以分号分隔 |
| `observed_ids` | dropout 后保留的 ID；ideal 模式与原始 ID 相同 |
| `dropped_ids` | 本时刻被 dropout 移除的 ID |
| `raw_target_detected` | 目标是否在理想检测列表中，0/1 |
| `target_detected` | 目标是否仍在 dropout 后列表中，0/1 |
| `target_dropped` | 目标是否本时刻被随机移除，0/1 |
| `ego_x_m`, `ego_y_m`, `target_x_m`, `target_y_m` | 世界坐标下参考点位置真值，m |
| `target_object_type`, `target_object_category` | 目标类型及该类型下的类别整数码，来自真值；漏检时仍记录 |
| `observed_target_object_type`, `observed_target_object_category` | 检测存在时的同一分类；漏检或不在视野时留空 |
| `ego_speed_mps`, `target_speed_mps` | 速度真值，m/s |
| `gap_m` | 投影到自车方向的包围盒边缘间距真值，m |
| `closing_speed_mps` | 纵向接近速度真值，m/s；正值表示接近 |
| `ttc_s` | 根据真值计算的近似纵向 TTC；无有限值时留空 |
| `observed_gap_m`, `observed_ttc_s` | 检测存在时的风险信息；不可见时留空 |
| `acceleration_command_mps2` | AEB 加速度指令，m/s²；负值表示减速 |
| `aeb_active` | AEB 是否已经锁存触发，0/1 |
| `collision` | esmini 是否报告自车当前存在碰撞，0/1 |

`objectType` 与 `objectCategory` 是模拟器内的枚举值；category 要结合 type 解释。
三个输入案例中的两个物体均由 XML 声明为 Vehicle/car。当前没有分类误差模型。

进入控制器之前，未检测到目标时 gap 被屏蔽为无穷大、closing 为 0、in_path 为 False。
CSV 用空单元格表达观测缺失；不应把空值解释成距离为零。真值列一直保留，
用于在相同物理定义下评价 off/on。感知 dropout 不修改真实车辆位置和类型。

`comparison.csv` 中的漏检率为 dropped_target_samples / raw_target_samples；
没有原始检测时为空。`longest_miss_s` 统计连续随机丢失目标的持续时间，
不包含目标原本不在理想传感器范围内的时段。最小 gap 只统计到首次碰撞或仿真结束。
制动已经锁存后，后续漏检不会释放制动，这是本控制器的明确假设。
