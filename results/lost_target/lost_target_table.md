# 目标丢失时用预测距离：对 HiDrive AEB 安全指标的影响

同样的场景、种子和漏检模式（p=10%）。一次只改一处：目标消失（2026-11-01 的 Detection 结果）→ 预测 → OU（100 m 处平均误差 1.4%，设定值）+ 预测。
Predict 和 OU + predict 只改目标距离，丢失期间车辆仍收到目标的真实速度。Predict, frozen motion 和 OU + predict, frozen motion 把这些运动量也停在最后看到的那一步，距离仍按冻结的速度差算。OU + predict, frozen object speed 的距离也只冻结目标速度，自车用实时速度。
这些都是设定值下的敏感性结果，不是实测风险。

- 碰撞：撞的次数/总次数，括号里是 95% 区间。
- 新撞/避开：同种子同漏检模式下，和目标消失相比，多撞的次数和不再撞的次数。
- 撞击：相撞那些次的相对速度中位数（km/h）。
- 触发推后：相对无误差那次，中位数（最小到最大），秒。
- 预测步触发：首次触发正好落在预测步上的次数。
- 最大高估/低估：预测距离和真实距离的最大差（米），高估即以为比实际远。
