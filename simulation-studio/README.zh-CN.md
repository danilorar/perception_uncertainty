## 0.9.0 / 2026-10-05：OU 时间相关测距误差与论文定位

新实验删除逐帧独立的固定高斯、距离高斯误差入口及实现，改为 `distance_ou_range`。对每个目标保存独立的归一化 OU 状态：`rho = exp(-elapsed / tau)`，`z = rho*z_prev + sqrt(1-rho²)*N(0,1)`，再将 `sigma(range)*z` 加到真实测距上。首次状态从平稳分布抽样；时间间隔采用同一目标两次探测之间的实际时间，缺测后按完整间隔推进，零误差区内状态仍演化。负测距不重抽样、不截断，记录为无效后不传给 AEB。有效观测直接进入控制，不使用卡尔曼滤波。

相关时间 `noise_correlation_time_s` 默认 0.5 s，可在实验设置中调整。距离幅度仍沿用零误差边界、参考距离和参考 MAE；这些数值与默认相关时间是敏感性试验设定，并非论文或实车标定值。增加相关性保持固定距离下的理论平稳方差，不代表每一帧都有变化上限，也不保证闭环结果更安全。

打开 `http://127.0.0.1:8976/#flow/noise`，右侧讲解给出公式、参数含义、边界处理及逐项文献依据。四份完整原文保存在 `assets/literature/`，参考资料支持下载 PDF、打开完整 PDF，以及按页定位并高亮引用关键词的本地阅读器。Turlej 用于时间相关感知误差的建模思路；Yang 等用于离散 OU 递推与方差归一化；Piazzoni 等用于时间因素和验证边界；SENSI 海报作为研究方向补充。讲解明确区分已实现内容、项目假设和扩展阅读。

示例配置为 `configs/correlated_range.json`。旧配置由界面载入时转换为 OU，命令行直接运行旧误差模式会被拒绝；已有历史结果仍按其原模型标注。新 `observations.csv` 增加归一化状态、相关系数及实际间隔，摘要记录模型、参数与文献来源。

97 项模型及回归测试、3 项资料与 HTTP 测试通过；`verify_correlated_noise.py` 的 8 组 esmini 检查覆盖三个场景的 OU/理想对照、同种子逐字节复现和零误差与理想模式一致性。证据位于 `verification/20261005T090231_correlated_noise/`。本次改动前备份位于 `work/before-ou-upgrade-20261005/`；下文保留较早版本的变更历史。

## 2026-09-30：按幅度分组共享纵轴

同一情境的结果图改为按实际幅度自动共享纵轴，防止一两张大幅度图把其余曲线压扁。每个指标分别计算：距离、距离误差、速度和加速度各自分组，横轴、时间刻度与绘图区尺寸继续全情境统一。此规则取代下文历史章节中的“全部记录强制共用纵轴”和“仅一条记录可独立”的限制。

算法从每条记录完整数据的极值出发，留 4% 余量并对齐易读刻度，按单独显示时的纵轴跨度从小到大分组。只有合并后的最终跨度不超过组内**任一记录自身跨度的两倍**时才共享，防止多条中间幅度记录把小图逐步拖入过大的范围。大幅度记录另组；相近的大幅度记录仍可共享。全部峰值保留，使用线性坐标；零误差组使用 −1～1 m。图底部在存在分组时标明每条纵轴的组号及记录数，组内可直接比较曲线高度。

新增、覆盖、删除或重新绘图时，均按当前保留的数据重算分组；不累积旧极值。显式 `plot_axes_policy.json` 独立纵轴例外继续优先，删除后恢复自动分组。`plot_axes.json` 版本为 4，各纵轴包含组号、组数与成员数；集合 `plot-axes.json` 的 `y_groups` 保存各指标的分组范围与成员。重绘前的图与元数据备份位于 `postprocessing-backups/before-shared-axes-v4/`，原始仿真数据保持不变。

## 2026-09-28：随预测距离调整 Kalman 测距权重

在“估计器参数 → 测距噪声假设”可选择“随预测距离调整”或“固定标准差 · 对照”。测试未显示新模式稳定改善误差，因此默认保留固定模式，“推荐 AEB 设置”保留用户选择的噪声假设。旧配置未包含 `kalman_noise_mode` 时仍使用固定模式，历史结果不改写；示例 `configs/aeb_kalman.json` 显式启用新模式。已运行的服务需重新启动才能加载 Python 改动。

在距离相关高斯误差下，设标准差曲线斜率为 `a = reference * mae_pct / 100 / (reference-zero) * sqrt(pi/2)`。新模式使用当前测量到来前的预测距离 `r_pred` 与预测距离方差 `P_pred`：

`R = max(0.1², a² * (max(0, r_pred-zero)² + P_pred))`

这是根据预测状态估计测量噪声的近似方法，不读取真实距离，也不根据本帧测距直接决定本帧权重。`P_pred` 补偿预测距离本身的不确定性；0.1 m 数值下限避免零方差锁死。首次及重新建立跟踪时，从第一条有效测距初始化，距离方差取 `max(kalman_range_sigma_m², sigma(first_measurement)², 0.1²)`。因此新模式下界面中的 10 m 是初始不确定性下限；固定模式仍全程使用 10 m。旧固定高斯误差模式仍采用固定 R。无误差与 raw 分支保持原行为。

`observations.csv` 新增 `assumed_range_sigma_m`：初始化帧记录初始距离标准差，后续滤波帧记录实际使用的 `sqrt(R)`，无滤波或无观测时留空。摘要记录噪声模式与算法定义。

目标速度和方位仍理想已知；负测距被拒绝造成的选择偏差尚未校正，不能声称精确匹配有效观测分布或保证制动更安全。`verify_adaptive_range.py` 在三个场景各用 20 个种子将相同回放观测送入两种滤波器，并运行三个种子的 AEB 闭环对照；结果写入新的 verification 目录。

### 界面操作

### 观测更新与仿真步长

`observation_period_s` 可选 0.02、0.05、0.10 s；0 保留旧版每仿真步抽样。非零时，观测时间轴独立于积分步长。积分网格会在观测时刻额外分步，例如 0.02 s 积分与 0.05 s 观测可以同时精确落点。每个观测时刻每个可见目标抽一次误差，积分中间步不重复抽样、不作为额外确认帧。

`observations.csv` 只在观测时刻写入；`truth.csv` 和 `ego.csv` 覆盖积分时刻及最终 9.98 s。若末帧不在观测时钟上，不额外生成一次测量。相同静态真实输入、相同种子和观测周期下，改变积分步长不会改变误差抽样序列。闭环轨迹若因数值积分略有变化，距离相关噪声的幅度仍可能随之变化。

### Kalman 的具体含义

`tracking.py` 只接收观测对象与自车状态，不接收目标真实位置、真实距离、噪声样本或未来目标轨迹。每个目标独立维护 `[中心距离, 距离变化率]` 两状态 Kalman 滤波器，使用恒速度预测和加速度过程噪声。

- 测距测量来自已经加噪的观测位置。固定模式的测距方差 R = `kalman_range_sigma_m²`，默认假定标准差 10 m；新模式规则见上文。两种模式均**不改变真实误差分布**。
- 本版延续“目标速度、方位、尺寸准确已知”的实验假设：距离变化率以相对速度在视线方向的投影作为辅助测量，使用 0.01 m/s 的数值标准差。控制器仍使用原有准确目标速度。本实验不评估速度测量误差。
- 过程噪声加速度标准差默认 3 m/s²；协方差使用 Joseph 形式更新。首次状态从第一条有效观测初始化，距离方差为 R，不使用真实距离初始化。
- 默认跟踪建立时间 0.15 s，且至少需要两条有效观测。建立期间保存估计值，但不送给 AEB。无效/缺失观测当帧不输出目标，不把预测轨迹伪装成新测量。连续缺失超过 `max(0.2 s, 2.5 × 观测周期)` 后重新建立。
- 随距离误差模型仍保留负原始测距并标为无效；有效子集存在选择偏差，Kalman 不会自动消除它。固定高斯旧模式保留其非负截断规则。较大噪声、偏差或模型失配仍可能造成早制动、晚制动或碰撞。

这些是可调的研究起点，未用这三个案例标定为某个真实传感器或车辆系统。参数调整需要同时检查距离误差、提前干预与晚制动。

### AEB 状态与接管方式

`aeb_trigger_mode=confirmed`：监测 → 同一目标持续危险确认 → 响应延迟 → 实际制动 → 停车。只有新观测更新危险证据；目标改变或出现安全/缺失观测，会在实际制动前取消待触发状态，包括响应延迟期间。实际开始制动后保持至停车，不因随后的单帧噪声反复制动/释放。确认时间、跟踪建立时间和响应延迟分别记录，不能混为一个延迟。

`instant` 保留单帧触发后持续制动的旧逻辑。它与 raw/Kalman 两种处理可自由组合。`first_trigger_time_s` 是第一次完成确认的时刻，即使之后取消；`first_brake_time_s` 是实际开始制动的时刻。CSV 每步保存 `aeb_state`，并保存取消确认次数。

新增 `controller=aeb_follow`（原始轨迹接管）：实际制动之前，自车逐点复现原位置、速度、方向和减速；实际制动之后，AEB 纵向控制**替代**原驾驶，按配置减速度积分，沿原自车路径的弧长前进。它不是把原制动与 AEB 相加。若配置的 AEB 减速度弱于原驾驶，该定义可能降低制动强度，应据此解释实验。路线末端不足时沿末端切线延伸，目标仍按原时间轴运动。自车初始速度和航向使用源值，界面只读。

原 `aeb` 保留恒速起步、固定航向的旧运动模型；`constant_speed` 与 `original_trajectory` 的原运动语义保留。原轨迹接管实验应以原始回放作为无 AEB 基准，不能与恒速基准混淆。

### 新指标与导出

每个 AEB 实验同时计算一条**独立的理想距离对照自车轨迹**，使用相同初始状态、基础驾驶方式、观测时钟、可见性规则及 AEB 触发策略，仅去除距离误差。该对照只用于诊断，不传给实际估计器或控制器；不调用额外 esmini，也不声称对照具有独立的引擎碰撞核验。

- `brake_advance_vs_ideal_s = ideal_brake_time - actual_brake_time`：正数为更早，负数为更晚；任一组未制动时为空。提前制动不是自动的“误制动”标签。
- `true_center_range_at_brake_m`：实际开始制动时的真实中心距离，不是车身净间距。
- `matched_observed_range_rmse_m` / `estimated_range_rmse_m`：在同一批有效且跟踪已建立的时间点比较观测与估计 RMSE；全体有效观测 RMSE 另存于 `observed_range_rmse_m`。回放与闭环组轨迹不同，不应跨组直接比较误差幅度而忽略距离分布。
- `stop_time_s`、`minimum_center_range_m`、`cancelled_confirmations`、观测帧数；碰撞记录新增两车相对速度大小。
- `observations.csv` 新增估计距离、估计距离变化率、估计标准差、跟踪状态、创新量、真正送给控制器的距离。
- `ego.csv` 新增 AEB 状态、新观测标记和独立理想对照速度。接管前 `command_accel_mps2` 留空，原驾驶估算加速度单独保存；该离线绘图估算不送给控制器。

判断无必要制动还需要没有碰撞威胁的独立场景。本版包含同向等速目标的控制逻辑测试，但三个老师案例仍全部是追尾事故案例，不能用它们声称获得总体误制动率。

### 配置兼容与验证

## 0.4：随距离增大的高斯误差

第三步新增“随距离增大的高斯误差”，默认参数为零误差距离 3 m、参考距离 100 m、参考处平均绝对误差 50%。原有高斯模式更名为“固定参数高斯误差”，旧配置继续使用原算法；原始数据模式仍为页面默认选项。

用户已确认“50%”指：100 m 时，所有高斯抽样的平均绝对误差为 50 m，正负误差对称。设真实中心间距离为 r，默认模型为：

```
E[|error| | r] = 50 * max(0, r - 3) / 97  (m)
sigma(r) = E[|error| | r] * sqrt(pi / 2)
error(r) ~ Normal(0, sigma(r)^2)
raw_observed_range = r + error(r)
```

3 m 以内及边界严格无误差；平均绝对误差以“米”为单位线性增长，100 m 以外沿同一斜率继续增长。默认 50 m 处平均绝对误差约 24.23 m，100 m 处为 50 m，对应标准差约 62.67 m。该规则是本次指定端点之间采用的线性模型，不是老师已提供完整公式的声明。

每个可见目标在每个仿真步独立抽样。同一配置、步长、种子可复现；改变步长会改变抽样率。距离仍按两车包围盒中心计算，不是车头与前车车尾的净间距。

由于高斯分布无界，较大误差会产生负测距。新模型不截断、不重抽误差；负的原始测距在 CSV 中保留，标为无效，并从控制器输入中排除。有效测量子集不再保证对称或平均绝对误差恰为 50 m，标定指标应使用完整的 `sampled_range_error_m`。3 m 内零误差仍受范围与视场角可见性限制。

`observations.csv` 新增 `raw_observed_range_m`、`observation_valid`、`range_error_mean_m`、`range_error_sigma_m`、`range_error_expected_abs_m`。`visible` 表示几何可见，`observation_valid` 表示能否提供观测。摘要保存模型定义与无效测距次数。新模型运行参数示例在 `configs/distance_gaussian.json`；`configs/gaussian.json` 也更新为新模型，旧固定模型仍可从界面选择。

按用户要求，结果界面不再显示“原始道路末段长度与 road length 不一致；保留老师道路并记录 esmini 提示。”这句话。该诊断仍保留在原结果摘要和 esmini 日志中，其他运行错误照常显示。

## 当前模型的准确含义

闭环：真值 → 对象观测 → 不确定性 → AEB → 自车运动更新 → 下一步。

- **感知原型**：在车辆包围盒中心之间的径向距离上加误差：`r_observed = max(0, r_true + bias + Normal(0, sigma²))`。每个可见目标、每个仿真时间步独立采样。同一模型、步长和种子可复现。
- **可见性**：按真实相对方位和距离应用水平视场角、感知范围限制；理想观测和误差条件共用这些限制。没有遮挡、漏检、时延、分类误差或融合模型。目标速度、朝向、尺寸在本版中视为准确已知。
- **AEB 原型**：用当前观测的位置、速度、朝向及包围盒，在双方保持当前速度和朝向的假设下预测首次矩形接触时间。当接触时间不大于阈值时触发；经过响应延迟后，用设定减速度持续制动至停止。控制器不读取目标未来轨迹，也不直接读取目标真实位置。
- **默认参数**：阈值 1.5 秒、制动减速度 8 m/s²、响应延迟 0.1 秒。它们是演示闭环的实验设置，尚未标定，也不是老师提供的正式 AEB 模型。
- **运动模型**：固定航向的二维运动，分段恒加速度积分，速度下限为零。没有轮胎、附着系数、制动压力建立或碰撞后动力学。
- **碰撞评估**：由 esmini 对真实包围盒的几何重叠判定，在每个仿真时间步采样。保存首次碰撞的时间、对象及自车速度，实验继续至原版基准结束时刻。无碰撞只表示运行时限内未检测到碰撞；有限步长可能影响接触时间，尤其在高速窄目标条件下。
- **视频**：从本次保存的真值重新渲染，25 fps、960×540、固定俯视取景，再编码为 MP4。视频是展示输出；指标来自仿真数据。视频采样不会改变仿真时间步长。

更换采样步长会同时改变独立噪声的采样频率，本版不能把不同步长下的噪声序列当作同一个连续随机过程。正式实验前需要确定更新率或时间相关误差模型。

待办：老师的正式不确定性模型及参数依据；AEB-s 的明确含义与规则；正式控制器/车辆模型接口；新增数据集适配；遮挡及其他感知误差；转向控制。未用自建原型冒充这些正式组件。

## 每次运行保存什么

结果目录：`runs/<UTC时间_场景_编号>/`。

| 文件 | 内容 |
|---|---|
| `config.json` | 完整实验参数 |
| `summary.json` | 执行状态、是否碰撞、碰撞时自车速度、触发/制动时间、目标轨迹一致性检查 |
| `ego.csv` | 自车真值速度、位置、航向、制动指令、预测接触时间及碰撞对象编号 |
| `truth.csv` | 全部对象的真实运动与包围盒数据，每个时间步每个对象一行 |
| `observations.csv` | 真值距离、观测距离、误差、可见性和观测位置；不可见时观测值为空 |
| `speed.png/svg`、`range.png/svg` | 可用于报告的曲线；SVG 为矢量图 |
| `video.mp4` | 可选的普通视频，可在浏览器或系统播放器观看 |
| `replay.dat` | esmini 专用回放记录，不是视频 |
| `fixed_reference.csv`、`reference.json` | 本案例基准及来源/哈希 |
| `scene.xosc` | 此次派生实验输入 |
| `versions.json`、`reproduce.ps1` | 软件/代码版本哈希与复现命令 |
| `esmini.log`、`video.log`、`ffmpeg.log` | 仿真及导出日志；失败时另有 `error.log` |

CSV 列名附单位。`speed_mps` 是 m/s，`speed_kph` 是 km/h，角度列明确区分 rad/deg。`range` 是包围盒中心间距离，不是保险杠净间距。`predicted_contact_time_s` 为空代表当前预测窗口内没有接触预测，不代表无限安全。

## 命令行与批量运行

在本目录打开 PowerShell：

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 '.\runner.py' run --config '.\configs\default.json'
& '.\.venv\Scripts\python.exe' -X utf8 '.\runner.py' batch --matrix '.\configs\batch_example.json'
```

批量文件包含 `base` 通用设置和 `runs` 差异参数列表。批量执行调用同一个单次运行核心，每个实验独立进程；汇总位于 `batches/<编号>/summary.csv`。失败实验保留状态，不算作“未碰撞”。示例的少量运行只演示批处理，不足以估计碰撞概率。

复现某次运行可执行其 `reproduce.ps1`，会创建一个新结果目录。代码更新后应比较 `versions.json` 中的实现哈希。重建本机环境时使用 Python 3.11 x64、`python -m venv .venv`，再安装 `requirements-lock.txt`；当前已配置，无需再次安装。迁移项目后应重建虚拟环境、基准及快捷方式，旧证据保留原始绝对路径。
