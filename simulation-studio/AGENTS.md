## 结果图比较规则

- 用户于 2026-09-29 要求：同一情境下、相同标题的结果图，横纵轴范围、刻度及绘图区尺寸必须一致，便于直接比较。
- 所有结果图通过 `plots.make_plots` / `plot_axes.sync_plots` 生成。按情境和指标共享坐标轴，不按随机种子、噪声、滤波器或控制器参数分别自动缩放。
- 新结果超出共享范围时，扩展范围并同步重绘同一结果集合内该情境的历史结果；保留原始仿真数据和首次改图前的备份。不要通过裁掉超界曲线维持相同坐标轴。

## esmini 运行环境

- 用户于 2026-09-29 要求使用完整 esmini。当前固定使用 `../esmini-lab/runtime/esmini-full-v3.8.1`（完整源码、官方 Windows 工具包及完整模型），不要恢复到 Demo 目录。
- 完整安装的来源和校验记录见 `../esmini-lab/evidence/full-install/`。新实验需在 `versions.json` 记录实际运行目录及 DLL 哈希；旧 Demo 与历史结果保留用于复核。

## 桌面服务启动

- 供用户使用的 `app.py` / `launcher.pyw` 服务必须以当前 Windows 桌面用户身份运行。受限账户 `CodexSandboxOffline` 可以生成仿真数据，但其 `os.startfile` 无法打开桌面资源管理器，会报 WinError 5。需要从工具重启服务时，使用获批的桌面账户执行环境并隐藏启动窗口；不要在普通受限执行环境中替换用户服务。
- 启动或复用后检查 `/api/health` 的 `process_user`。服务仅监听本机；不得为解决打开文件夹的问题修改目录 ACL 或关闭安全限制。已有实验运行时通过正常接口等待退出，不强制终止。
